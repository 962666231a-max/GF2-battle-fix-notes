# GF2 支付 SDK 真实对应结构（反汇编实证）

> 本文件是"完美复刻"的依据：所有字段名与判定条件都来自 `GameAssembly.dll` 反汇编 + 解密后的 il2cpp 元数据，
> 不是猜测。客户端版本 4.0.5136。

## 0. 前置：为什么要反汇编

- 磁盘 `GF2_Exilium_Data/il2cpp_data/Metadata/global-metadata.dat` 是**加密**的（Il2CppDumper 报 invalid metadata）。
- 运行时解密后的副本在进程内存里：区域 `VA=0x2A60DCF9000`，长度 `17,924,096` 字节，元数据魔数 `0xFAB11BAF` 位于区内 `+64`。
- 用该副本 + `GameAssembly.dll` 跑 Il2CppDumper，**版本号需改成 24**（原始值 `0x01117CE8` 被改过），得到 `dump.cs` / `script.json` / `stringliteral.json`。
- 再用 capstone 反汇编 `GameAssembly.dll`（ImageBase `0x180000000`），把 `[rip+disp]` 还原为绝对地址，去 `stringliteral.json` 查字符串。

## 1. 下单：`POST /alipay/create_order_qr`

### 请求（客户端 → 服务器）

```json
{
  "device_num": "<设备指纹>",
  "request_id": "<uuid>",
  "product_id": "com.sunborn.SnqxExilium.cn.diamond1",
  "channel_openid": "<openid>",
  "amount": 600,
  "os": 3,
  "subject": "信用币×60",
  "mac": "",
  "monetary_unit": "CNY",
  "reyun_channel_id": "1038",
  "game_channel_id": 5,
  "sub_id": "1038",
  "language": "cn"
}
```

请求头带 `Authorization: base64({"openid","expires","is_guest","uid"}) + "." + 签名`。

### 响应（服务器 → 客户端）★ 关键结构

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "limit": 0,
    "param": "https://…/qr?order=1794360643747",
    "order_id": "1794360643747"
  }
}
```

### 反汇编依据（`MTSDKApi.HttpClient.<>c__DisplayClass39_0.<CreateOrderByQR>b__0`）

```c
inner = data["data"];                 // JsonData.get_Item —— 缺 key 直接抛 KeyNotFoundException
if (inner 是对象/JsonType.Object) {
    limit    = inner["limit"];        // 必须存在
    param    = inner["param"];        // 必须存在
    order_id = inner["order_id"];     // 必须存在

    if (limit 是对象)  onAntiLimitPay(limit);                       // 限流/风控分支
    else if (param 是字符串 && order_id 是字符串)
        onCreateQROrderSucc(param.ToString(), order_id.ToString());  // ★ 成功：param 即二维码内容
}
```

**注意两点（都是当初卡住的原因）：**
1. `limit` 也必须存在。三个 key 都是 `get_Item`，没有 `TryGetValue`，缺任何一个都会抛 `KeyNotFoundException`。
2. `param` / `order_id` 必须是**字符串**（JsonType.String），才会进成功回调；`param` 的值就是二维码的内容。

## 2. 轮询：`POST /order/qr_confirm`

### 响应

```json
{ "code": 0, "msg": "ok", "data": 1 }
```

### 反汇编依据（`<RequestQROrderState>b__0`，304 字节）

```c
if (payRequestId != null) ClearPayRequestId();
d = data["data"];
int v = (int)d;                     // 直接把 data 转 int
if (v == 1) onOrderPaySuccess.Invoke();   // ★ 1 = 已支付
```

`data` 必须是**整数 1**，不能是对象或字符串。
